# Netflix Content Analytics Dashboard

An interactive Streamlit dashboard for exploring Netflix movies and TV shows.

## Features

- Filter titles by Movie or TV Show
- View key dataset metrics
- Analyze content growth over time
- Explore top genres, countries, and ratings
- Clean missing values for director, cast, country, and genre fields

## Tech Stack

- Python
- Pandas
- Plotly
- Streamlit

## Run Locally

```bash
pip install streamlit pandas plotly
streamlit run app.py
