# Netflix Content Analytics Dashboard

An interactive data dashboard built with Python, Streamlit, Pandas, and Plotly to explore Netflix movies and TV shows.

## Project Overview

This project analyzes a Netflix titles dataset and presents key insights through an interactive web dashboard. Users can filter the dataset by content type and explore trends in Netflix's catalog, including release history, top genres, ratings, and producing countries.

## Features

- Filter content by Movie or TV Show
- View dataset preview and key metrics
- Analyze Netflix content growth over time
- Explore top producing countries
- Compare top genres by selected content type
- View content rating distributions
- Handle missing values in director, cast, country, and genre fields

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Key Insights

- Netflix content increased significantly after 2015
- Movies make up the majority of Netflix titles
- The United States is one of the largest content-producing countries
- Drama and international categories are among the most common genres
